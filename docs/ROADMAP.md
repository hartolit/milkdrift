# Roadmap

This document owns ordered unfinished product slices.

1. Add the live capability registry, policy-constrained resolution, causal context construction, secrets and authority mediation, audited effect dispatch, and the first process/model adapters without weakening the durable execution contracts.
2. Add bounded workflow-control capabilities for authorized AI controllers, using the same commands, prospective plans, approvals, and audit trail as humans.
3. Add peer capability advertisement and invocation over pluggable user-provided connectivity.
4. Add a daemon that owns durable state and places blocking local storage behind a bounded host executor.
5. Add thin versioned CLI and Iced clients for authoring, operation, reconciliation, and inspection.
