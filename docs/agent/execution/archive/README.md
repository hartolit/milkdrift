# Completed execution prompts

This directory preserves completed prompt and work-package inputs for historical
decision provenance. These files are not current instructions and do not need to
be loaded for ordinary execution. Current authority is limited to
[`../current.md`](../current.md) and
[`../execution-plan.md`](../execution-plan.md); durable completion evidence lives
in [`../history.md`](../history.md) and canonical project documentation.
