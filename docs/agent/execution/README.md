# Execution documentation

This directory owns immediate program state and concise chronology. It does not
own current architecture, component behavior, product support, procedures, or
measurements.

## Current execution authority

- [Current context](current.md) records an active package or explicit parked state,
  immediate tree boundary, unresolved acceptance, and environment-specific handoff.
- [Execution plan](execution-plan.md) records the ordered active/inactive program.

These are the only live execution authorities. Current project facts remain in
the [project documentation](../../project/README.md).

## Historical execution

- [History](history.md) is the milestone and evidence ledger. Historical claims
  remain tied to the commit/tree that produced them.
- [Archive index](archive/README.md) identifies removed completed prompts and their
  durable outcomes. Prompt bodies remain available through Git history and are not
  required reading.

Do not add phase-completion reports, command transcripts, copied support matrices,
or completed prompt bodies here. Append one compact history entry when a meaningful
milestone closes.
