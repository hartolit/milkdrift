## Consequential conflicts and conditional choices

**I01:** U05's generic text-node explanation conflicts with observed structured types, but its
underlying complaint about expression remains legitimate. Compare generic operation schemas,
typed runtime control and standards foundations in 03/05. Do not treat correcting the factual
description as disproving the user's authoring problem.

**I02:** U07 contains both a proposed reusable collapse and doubt about the remote bridge. It
does not require universal publication. The 02 trial compares shared discovery and explicit
actions while preserving the value of restricted calls. User preference about defaults remains open.

**I03:** The vision's headless-first sentence and prescribed Canvas/Timeline/Inspector are
implementation-era choices. U01/U04 authorize redesign now; the future program must bring real
connected use forward so backend assumptions can be corrected. This does not authorize a prototype.

**I04:** Adaptability and dependable acceptance are compatible only when the boundary of permitted
change is explicit. Existing governed regions are a candidate mechanism, not proof that this
planning workload fits. A changed agreement requires a new authorized boundary; a process that
must change its protected obligations cannot silently claim ordinary repair. S26/S28 must test both.

**I05:** Standards preference is explicit; improved model performance and interchange are separate
unproven claims. Prepare a fair authoring exercise; do not use claimed model expertise to select
semantics. No paid-provider experiment is authorized by planning scope.

**I06:** “Standalone” establishes independence from one daemon, not browser packaging, a central
broker, automatic network connectivity or credential sharing. Browser observations discriminate
transport feasibility; packaging preference remains a review choice with costs.

The original transcript gap blocks claims about the user's exact preferred defaults and retiring
meaningful abilities. It does not block a complete proposal preserving those abilities with
explicit choices. No canonical product document is changed by this register.
