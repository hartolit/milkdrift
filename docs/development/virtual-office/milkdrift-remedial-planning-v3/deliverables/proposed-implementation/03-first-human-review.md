# P03 — Obtain real user critique and repair its consequences

Owner: implementation coordinator and actual user; independent critic reviews resulting decisions.
Requires the working P02 frontend. Read [shared context](context.md), G1/P1/P2/A1/N1/F1, current
interface and the user's new feedback. An agent walkthrough is not completion of this checkpoint.

Present the real connected application with a disposable method/brief and no private deployment.
Let the user connect, find work, author/edit, run, inspect a failed/denied outcome and recover a lost
observation. Include same-name owners and pin/copy/service discovery using only implemented paths;
show unavailable advanced actions honestly. Capture the user's actual observations and words, not
a predicted positive review. Missing availability pauses this checkpoint; do not invent acceptance.

Classify each substantive observation: presentation friction, missing public behavior, mistaken
product premise, provider/model limitation, or an unresolved preference. A screen complaint can
expose backend ownership; do not limit this review to visual polish. Trace source and compare a
smaller complete correction with structural alternatives. Reopen only affected G/P/A/N/F decisions
and downstream P04–P09 premises. Preserve earlier dissent and context.

Implement authorized corrections end to end with their owner and consumers. If a change removes
meaningful ability or broadens trust, prepare a concrete tradeoff for user decision before dependent
implementation. Do not retain contradictory workflows as configurable modes merely to avoid a
decision. Known defects discovered here are repaired here, not handed knowingly to P09.

Acceptance: user feedback is authentic and linked to changed decisions/text/code or a precise
unapproved tradeoff; changed interactions pass their positive, refusal and recovery checks. A
reviewer can explain which later assignments need rereading and why. Run focused affected tests,
frontend checks and docs; commit coherent fixes regularly. Resume advanced work only with a current
context packet and explicit unresolved branches. Human use qualifies only exercised tasks/environment.
