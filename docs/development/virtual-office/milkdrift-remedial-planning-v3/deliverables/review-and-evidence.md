## What changed because of criticism

Recovery storage became a prerequisite before send, rather than an optional warning after losing
requests. Workflow replay's exact authority was distinguished from current-authority inspection and
direct serving's stored-basis replay. The bounded merge gained explicit data exits, optional/nested
forwarding, atomic selected evidence, useful future repair and separation from physical settlement.
The frontend gained lossless numeric handling, declared CSP endpoint topology and reserved stop
recovery capacity. Missing goal/study discovery work gained complete assignment owners. Private
service links remain private even after their containing public card survives a grant change.

The final source audit also corrected a common mutable-head assumption: definition authoring checks
the envelope against an immutable base, while valid sibling descendants can both save. A1/F1/F2
advance to r3 and P02/P04 now require positive divergent-save behavior and real base-mismatch refusal.
No new shared editing head is invented. The generated-program reader also corrected the wrapper's
NoExternalEntry versus entered-writer PhysicalStop distinction and the summary of actual trial
hypotheticals. These late corrections received focused rereads, not an invented earlier approval.

Primary-source rechecks also prevented false remedies: the daemon already computes layout author/
digest, and AuthorityRead already supplies stable host/actor/grant identity. No new API is justified
for those facts. Architecture's “any successful” sentence does drift from distinct Any-completion
and FirstSuccess code; P00 will correct prose if the plan is adopted.

The recurring failure was treating one surface as the whole contract: types without consumers,
control without data/lifetimes, native HTTP without browser policy, or one replay helper as universal.
The proposed practice is a narrow interaction-to-owner trace and independent positive/refusal/recovery
oracle, not more layers or a mandatory committee. Canonical practices remain unchanged until adoption.
