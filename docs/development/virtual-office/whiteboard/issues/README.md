# Whiteboard issues

Record a suspected or established implementation problem using the [whiteboard procedure](../README.md).
Start with a paragraph or these optional prompts; omit empty sections:

- What happened, what was expected, and who or what is affected?
- What source trace, reproduction, test, or product rule supports the report? What is still uncertain?
- Why does the needed investigation or fix extend beyond the current assignment?

Put the next useful step and other planning fields only in the [overview](../README.md#overview).
As investigation develops, add a concise technical assessment and substantive dated contributions
under actual agent pseudonyms. Do not duplicate status, assignment, or last-evaluation fields here.
