## Scope and reviewed corrections

The [assignment](../06-integrated-acceptance-and-closure.md) owns acceptance. Current supported
behavior belongs to [status](../../../../product/status.md), the operator route to the
[Slotbook example](../../../../../examples/adaptive-slotbook/README.md), and resource recovery to
[managed operations](../../../../operations/managed-linux.md).

This implementation completes the following corrections through existing owners:

- Authorized return of a published child's editing claim preserves the wrapper's durable
  `NoExternalEntry` proof. A wrapper cannot become a physical writer after recovery. Resumption
  uses the exact original caller's current authority, not the child's service grant or an unrelated
  administrator's grant. Physical parents retain their separate fresh-entry transition.
- Remote invocation renews the origin lease between submission retries and acceptance lookup,
  during productive observation streams, and across artifact metadata/transfer/cleanup boundaries.
  A rejected renewal stops further execution requests; lost replies retain the original request.
- Private container-network preparation opens and identifies the Linux TUN device. A stale device
  node without a usable driver no longer passes preflight. It neither creates an interface nor
  weakens isolation. Systemd launch guidance explains the daemon's own controller delegation.
- The installed-host evidence driver checks configured roles and peer identities, bounded pages,
  successful terminals, archived outputs, retained invocation identities and downloaded bytes.
  It drives actual CLI endpoints; it does not construct a privileged host in process.
- Learning cleanup and source-study cleanup compare the observed generation, recipe, accepted
  evaluation, complete resource inventory and preserve dispositions before mutation. Pending work,
  replacement generations and destructive disposition changes refuse cleanup, including on resume.
- The bounded source driver submits real structured proposals through a narrowly scoped advisor.
  It preserves returned mutation/source bytes, stamps authenticated model provenance, retains
  compiler/verifier diagnostics with explicit omissions, and stops on uncertainty. Resume binds
  image, model-profile bytes, lane and port. The learning model template is embedded for installed use.

The review traced these paths through production callers, authority/storage transitions and tests.
