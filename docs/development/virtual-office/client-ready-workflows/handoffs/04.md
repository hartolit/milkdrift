## Public route and limits

`workflow list --workflow ID`, `workflow show REVISION` and `workflow copy REVISION NEW_WORKFLOW
--name NAME --file NEW_DRAFT` use public reads and `copy_blueprint`. Copies preserve graph facts
and record the exact source in immutable revision provenance. They transfer no run inputs, outputs,
grants, reservations or editing claims. Protected agreements bind workflow identity: independent
copy refuses them instead of deleting protection or silently resealing. Reuse an exact governed
version or explicitly author another governed method. No preferred-version registry was added.

`method prepare CHOICES --output METHOD` submits `prepare_method` with explicit `PublicationDraft`
choices. The publication owner resolves agreement and configured grant facts and validates the
existing contract. It does not publish. `method publish` remains separate. `invocation prepare
... --input brief=FILE --output REQUEST` uses the same bounded restricted-text upload as ordinary
run starts, retains an artifact reference and refuses existing destination files before upload.
Upload/read authority remains separately scoped; invoke-only output permission does not grant it.

`learning select`, `declare`, `candidate`, `compare`, `inspect` and `promote` format ordinary public
learning requests. `select_sources` resolves permitted artifact identities before freezing the
existing selection. Receipt pairs remain explicit; inspection retains the original receipt
identity and shows the full fixed result, including missing values and reasons. Advanced
`learning FILE` remains supported. The daemon still authenticates actual candidate provenance and
derives scores. A valid publication document alone cannot qualify for promotion.
