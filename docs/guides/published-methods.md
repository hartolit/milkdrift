# Published workflow methods

Workflow publication as a capability was retired when ordinary daemon task workflows replaced the graph-oriented workflow
product. The decision and preserved independent host/resource boundaries are recorded in
[ADR 0051](../decisions/0051-daemon-task-workflows.md). Use the current
[operator recipe](../../examples/operator/README.md) and [task HTTP API](../reference/control-api.md)
for executable work. This stable documentation path contains no legacy operating procedure.
